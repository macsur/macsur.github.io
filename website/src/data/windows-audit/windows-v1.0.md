# Windows 桌面脚本专区 · 首批清单（终版 v1.0）

状态：2026-10-10 定版。经编制方逐仓核实、Muse 裁决、小安独立审计、用户拍板四道工序，作为立项开发的收录依据。

## 定版口径

- 总数 35 条，目标 60 个的首批，后续按周补齐。
- 形式：独立栏目、独立页（方案 B），不做 w 入口；编号 W001 起连续，只用于排序、书签与反馈。
- 混编加标签（用户 2026-10-10 拍板）：专区接受脚本与高价值工具混编，每条必须标注形态，四种形态为：脚本、工具、安装入口、运行环境。
- 交付：卡片加可复制命令加可选下载，第一版只复制与下载，不做点击即远程执行。每条写清来源、权限、改动点与回滚方式，并给源码链接。
- 门槛：只收来路清楚、代码可审计、仍在维护的开源项目；激活与破解类一律不收；闭源软件不收；仓库已归档或长期停更的不收。
- 风险口径：低为常规使用基本无系统性风险；中为会改系统设置或批量操作，需看清说明、先建还原点；高为深度改动系统，只适合懂行用户。页面固定风险提示按方案存档第 8 条执行。
- 审计修正已全部落入本版：交付标注纠正（W007 系统入口、W027 命令启用、W034 改复制命令）、风险修正（W016 上调、W005 与 W031 加限定口径）、来源修正（UniGetUI 新仓库地址、许可证不凭 API 猜测标注）。
