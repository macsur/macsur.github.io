## Web UI 适合做什么

- 快速理解陌生仓库
- 拖入 ZIP 临时分析
- 看知识图谱与聚类
- 做演示与分享

---

## 与 CLI 的区别

### Web UI
- 上手快
- 无需安装太多东西
- 更偏探索与展示

### CLI + MCP
- 更适合长期开发
- 更适合大仓库
- 更适合 AI 编程工作流

---

## 本地运行

```bash
git clone https://github.com/abhigyanpatwari/gitnexus.git
cd gitnexus/gitnexus-web
npm install
npm run dev
```

> **GitNexus Web UI 很适合做“第一次接触仓库时的全局地图”。**
