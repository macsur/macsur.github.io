# OpenAI Token 专题通道｜01：临时邮箱被封？3 步用域名邮箱绕过风控（Cloudflare 收信 + Python 自动注册）

> 一句话总结：**别再用公共临时邮箱硬刚风控了**。换成你自己的域名邮箱（只收验证码），成功率直接起飞。

## 封面段落（小红书开场）
你是不是也遇到过：
- 临时邮箱一注册就被拦 / 账号秒风控
- 好不容易注册上，额度/功能很快异常

这篇就是“可照抄”的版本：用 **Cloudflare** 搭一个「只收信」的域名邮箱，再跑一个 **Python 脚本**自动注册。

**收益**：脚本跑完会把 *账号/密码/Token* 存好，你后续直接用。

> 适合谁：经常折腾 OpenAI/ChatGPT 注册、需要稳定拿到 Token 的人。

## Step 1：Cloudflare 搭“只收验证码”的域名邮箱（越简单越好）
很多人一听“自建邮箱”就慌：SMTP/IMAP/反垃圾/证书……

Stop。你只需要两件事：
- 能收到 OpenAI 发来的验证码邮件
- 能看到验证码内容

> 核心思路：**只收，不发**（只做 inbound）→ 配置量直接少一大半。

### ✅ 步骤卡片（照抄）
1) 把域名 DNS 托管到 Cloudflare
2) 打开 Cloudflare 的 Email / Routing（收信路由）相关功能
3) 配一个规则：让 `@你的域名` 能接收邮件（至少能接收 OpenAI）
4) 用一次真实的验证码邮件验证：能收到、能看到内容

### 建议截图点（发小红书超加分）
- 「Email Routing」的规则页面（能看到你的域名）
- 收到 OpenAI 邮件的日志/记录（证明“能收”）

---

## Step 2：跑 Python 自动注册脚本（关键：验证码手动输入）
### ✅ 步骤卡片（照抄）
1) 用 Python 运行脚本
2) 脚本触发发送验证码到你的域名邮箱
3) 你把验证码**手动粘贴回终端**
4) 脚本输出并保存：账号 / 密码 / Token

> 为什么要手动输验证码？
> 因为“全自动读验证码 + 批量注册”更像机器人；**手动输入反而更像真人**，成功率更稳。

## Step 3：源码里通常只改 1 个点：邮箱后缀（domain）
视频里提到：脚本默认内置了作者的邮箱后缀（临时域名）。

### ✅ 步骤卡片（照抄）
- 打开脚本源码
- 搜索 `@` 或 `domain`
- 把默认后缀改成你自己的，比如：`@yourdomain.com`

其它逻辑一般不需要改。

## 避坑清单（抄这个就不会翻车）
### 1）别再用“公共临时邮箱域名”批量注册

## FAQ
### Q1：我不会搭邮箱，能不能“更傻瓜”？
可以。你只要满足“能收验证码”这个条件即可。

### Q2：OpenAI 会不会也封我自己的域名？
可能性显著更低，因为域名是你长期持有、使用路径更像真人；但如果你短时间高频批量注册，依然可能触发风控。
