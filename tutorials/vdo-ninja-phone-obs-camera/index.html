不用采集卡，手机秒变 OBS 高清摄像头：VDO.Ninja 实测教程

一条链接把手机变成 OBS 的横屏高清摄像头，安卓、iPhone 都行，全程实测过的坑一次说清。

正在用推荐

不用采集卡，手机秒变 OBS 高清摄像头：VDO.Ninja 实测教程

直播、录课、开会想多一个机位，手边最近的其实就是手机。买采集卡要花钱、还要接线；用 VDO.Ninja 一条链接就够了：手机负责拍，画面和声音直接进电脑上的 OBS。这篇是完整实测版——照着做能通，我们踩过的三个坑也一并写在下面，帮你一次到位。

先说清原理（30 秒）

VDO.Ninja 是个免费的网页工具，基于浏览器的实时传输（WebRTC），不用装 App、不用注册。它生成的链接分工很明确，这是全篇最重要的一句：

  • push 链接给手机：手机打开它，就是往外推流的「摄像机」；
  • view 链接给 OBS：加进 OBS 的浏览器源，就是收画面的「播放器」。

新手最常见的翻车，就是把 push 链接当播放地址填进 OBS——怎么等都是黑屏。两条链接长得像，用途完全相反，先记住这一点，后面全顺。

第一步：在 VDO.Ninja 建一个可复用的邀请

  1. 电脑浏览器打开 vdo.ninja，选「Create Reusable Invite」（创建可复用邀请）。
  2. 页面会生成三条链接，其中两条是我们要的：
  • 绿色那条是 Guest 链接（带 push=），给手机用；
  • 红色那条是 OBS Browser Source 链接（带 view=），给 OBS 用。
  1. 链接里的 ID（本文用 XXXXXXX 代替）就是你的频道号，不要公开晒出完整链接，谁拿到都能往你的频道里推流。这组链接不过期，以后每次用同一组就行。

第二步：OBS 里加浏览器源

  1. OBS 左下「来源」点 +，选「浏览器」。
  2. URL 粘贴上一步的 OBS 链接（view 链接），宽度填 1920、高度 1080。
  3. 勾上「通过 OBS 控制音频」，这样手机的麦克风也会跟画面一起进来、在混音器里能调音量。
  4. 确定。没人推流的时候它是黑屏、中间一个 ⓘ 图标，这是正常的等待状态——第一次用别被吓着去乱点刷新。

第三步：手机开推

  • 安卓：用 Chrome 打开 Guest 链接；苹果：用 Safari 打开同一条链接。
  • 允许摄像头和麦克风权限，看到自己的画面后，点 Join / 开始，把页面停在前台、屏幕保持常亮。
  • 回到 OBS，1～2 秒后画面就进来了，混音器电平跟着跳，声音也通了。

第四步：横屏满幅（全篇的精华，实测对比过）

手机竖着拿推流，手机预览看着没毛病，但 OBS 里会是「竖条居中、两边大黑边」；更坑的是，中途把手机横过来，画面内容会转 90 度、甚至直接断流——因为安卓 Chrome 的采集方向不跟随手机旋转。解法是给两条链接各加一个官方参数，一劳永逸：

  • 手机用的推流链接末尾加：&forcelandscape（推流端强制 16:9 输出，不管手机怎么拿）；
  • OBS 的 view 链接末尾加：&forceviewerlandscape（观看端把画面摆正）。

加完之后就是 1920×1080 全幅横屏、画面正向、没有黑边，手机横着竖着都无所谓了。

第五步：iPhone 用户多注意三件事

我们同一条链接、同一台电脑，拿安卓机和 iPhone 对照实测过：iPhone 画质明显更干净（本篇后文结论同此）。但 iPhone 起推前有三件事，缺一件就可能一直黑屏转圈：

  1. OBS 的 view 链接把编码改成 h264：链接里 codec=vp9 改为 codec=h264。iPhone 的 Safari 不吃 VP9；改成 h264 对安卓也没有任何影响，一次改好、两边通用。
  2. 同一条邀请同时只能有一台手机推流：换手机前，先把之前那台的推流页面彻底关掉，别让它占着位置。
  3. 推流前先关掉手机上的 VPN/代理：WebRTC 的媒体流容易被代理挡住，在 OBS 里就表现为永远在转圈。关掉重推，立刻出画。

另外一条是所有手机通用的：推流时不要锁屏、不要把浏览器切后台，断了的话 OBS 会回到黑屏等待状态，重新打开链接起推就能恢复。

画面糊怎么办

先分清是「糊」在分辨率还是码率。如果是满幅了但细节发软，多半是推流链接自带的码率偏低（邀请默认给得比较保守）。官方支持发送端参数：把推流链接里的 bitrate 数值调高（比如 8000），并加上 &width=1920&height=1080 锁定发送分辨率上限。注意码率不是越高越好，它吃你家里的 Wi-Fi 和上传带宽，画面稳、不卡，比参数拉满更重要。

总结

  • 链接别拿反：push 给手机，view 给 OBS；
  • 横屏满幅靠两个参数：推流端 &forcelandscape，观看端 &forceviewerlandscape；
  • iPhone 记得 h264、关 VPN、一邀一机；
  • 手机屏幕保持常亮、页面保持前台。

做完这四点，一部闲置手机就是一台随时能用的 OBS 高清摄像头，直播多机位、录课、远程会议都够用了。
