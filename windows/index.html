Windows 桌面专区

独立收录 Win10 / Win11 桌面可用的高价值脚本与工具，与 Linux 服务器线并行，不混编编号与入口。

使用前先看说明；建议先建系统还原点；需管理员权限的条目已标出；个别工具可能被杀软误报；本站只做收录与展示；内容有争议先下架。
