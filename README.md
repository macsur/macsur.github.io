## 📖 关于 MacSur

**MacSur** 是一个开源的 macOS 效率工具集合，汇集了 **网络代理、智能助手、媒体服务、自动化脚本** 等 30+ 实用工具。

本项目文档站收录了 **17 个详细教程**，涵盖：

## 📦 快速开始

### 1️⃣ 浏览教程

```bash
# 侧边栏导航
左侧目录 → 选择感兴趣的分类 → 点击开始学习
```

### 2️⃣ 搜索功能

右上角搜索框：
- 🔍 全文检索（标题 + 内容）
- 🏷️ 标签过滤（支持 `tag:技巧` 语法）
- 📅 按日期排序

### 3️⃣ 离线阅读

```bash
# 使用 Docsify CLI 本地预览
npm i -g docsify-cli
cd /Users/ttnk/.openclaw/workspace/macsur-docs
docsify serve .

# 浏览器打开 http://localhost:3000
```
