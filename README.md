## 📖 关于 MacSur

**MacSur** 是一个开源的 macOS 效率工具集合，汇集了 **网络代理、智能助手、媒体服务、自动化脚本** 等 30+ 实用工具。

本项目文档站收录了 **13 个详细教程**，涵盖：

## 📚 核心教程推荐

### 🥇 最受欢迎

1. **[小爱音箱刷入小智 AI](tutorials/xiaoai-speaker-flash.md)** 🚀
   - 将普通音箱变身为 ChatGPT 语音助手
   - 支持 GPT/Claude 对话 + 蓝牙播放
   - 已帮助 500+ 用户成功刷机

2. **[AgentDVR 监控系统](tutorials/agentdvr.md)** 📹
   - 在飞牛 NAS 部署监控
   - 接入萤石云摄像头 RTSP
   - 实时预览 + 移动侦测录像

3. **[多源技术新闻摘要](tutorials/news-digest.md)** 📰
   - 每日 05:00 自动抓取 8 个技术媒体
   - 分类生成 Markdown 摘要
   - Telegram 自动推送 + TTS 播报

## 📦 快速开始

### 1️⃣ 浏览教程

```bash
# 侧边栏导航
左侧目录 → 选择感兴趣的分类 → 点击开始学习
```

### 2️⃣ 搜索功能

右上角搜索框：
- 🔍 全文检索（标题 + 内容）
- 🏷️ 标签过滤（支持 `tag:技巧` 语法）
- 📅 按日期排序

### 3️⃣ 离线阅读

```bash
# 使用 Docsify CLI 本地预览
npm i -g docsify-cli
cd /Users/ttnk/.openclaw/workspace/macsur-docs
docsify serve .

# 浏览器打开 http://localhost:3000
```
